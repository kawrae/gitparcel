Quick guide

  1. Add your sources

    Paste a public GitHub repository, subfolder, release tag, or asset link. Add more links to combine repositories.

  2. Choose what to include

    Filter and select files in Bundle contents. Store keeps the original bytes, while Deflate compresses them. Choose up to 512 MiB per archive.

  3. Download your ZIP

    GitParcel fetches up to six files at once and builds the archive in this tab. The app server streams public release assets when GitHub blocks a direct browser download.
